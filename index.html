Research Projects

Dialect Speech Transcription System for Sichuan–Chongqing Dialect
  • Designed and implemented a high-accuracy speech transcription system using Paraformer-large (Alibaba ASR model) as the base framework, built from a ~29,000-utterance subset of the open-source KeSpeech dataset.
  • Proposed a partial-parameter-freezing fine-tuning strategy, freezing low-level acoustic modules and fine-tuning only high-level semantic layers, to mitigate overfitting under limited dialect data.
  • Reduced character error rate from 9.5% to 7.05% on KeSpeech and from 18.2% to 7.6% (58.2% relative reduction) on the WSC-Eval cross-corpus evaluation set; further reduced CER to 6.47% by integrating Qwen2-1.5B-Instruct as a post-correction module.
  • Built and deployed an interactive demo system (FastAPI, Gradio) achieving a real-time factor below 0.02 on an RTX 4090 GPU.
Real-Time Illegal Content Detection in Livestream Video
  • Designed and led development of a system to detect illegal behaviors (false advertising, exaggerated claims) in e-commerce livestreams by combining speech-to-text transcription with a BERT-based classification model.
  • Tested multiple data augmentation strategies to address training data scarcity, then applied domain-specific fine-tuning to improve detection accuracy and robustness.
Vision-Guided Robotic Box-Handling System
  • Contributed to a computer-vision-based robotic system (Atlas development board) for object recognition and automated box-handling.
  • Developed the communication module linking the Atlas board and the robot controller, enabling coordinated hardware–software control between the vision-recognition module and the robot's action execution.
